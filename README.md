# BDA400 Assignment 2 — Technical Analysis using R

## Files
- `portfolio.txt`: stock symbols, one per line.
- `technical_analysis.R`: package setup, stock-data import, statistics, tables, charts, and CSV exports.
- `Assignment2_Report.docx`: report template and setup instructions.
- `screenshots/`: place your own screenshots here if you wish to keep them with the project.

## Run it
1. Install R and RStudio.
2. Open the `Assignment2` folder as the working project/folder in RStudio.
3. Open `technical_analysis.R`.
4. Run the script. The script will install any missing packages and then download the latest available historical data for the symbols in `portfolio.txt`.
5. Check the `output` folder created by the script for the summary and per-stock CSV files.

The script needs an internet connection. Yahoo Finance data availability can change, so rerun it before submitting and confirm the script completes successfully.
